# Roth IRA Advisor — Manager Desk

**Built by [Akshay Bhatkhande](https://github.com/akshay-bhatkhande) · Coded with AI (Cursor)**

Product direction, requirements, and portfolio workflow by Akshay. Implementation assisted by AI.

A self-contained browser tool for reviewing an E\*TRADE Roth IRA export like a portfolio manager: full-book research, beta-based risk, next-day outlook, and whole-share buy/sell tickets.

## Use it

1. Open the live page (GitHub Pages) or open `index.html` / `RothAdvisor.html` locally.
2. Drop in an E\*TRADE `PortfolioDownload.csv`.
3. Pick a target beta / risk level (holding splits + cash auto-recommend).
4. Click **Run analysis**.

Your CSV stays in the browser. Nothing is uploaded to a server.
